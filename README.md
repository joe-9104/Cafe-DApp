# Cafe-DApp

DApp avec blockchain Ethereum pour modéliser la validation d'un dossier de café auprès des autorités.

## Structure du projet

```text
cafe-dapp/
├── contracts/
├── scripts/
├── test/
├── frontend/
├── artifacts/
├── docs/
├── hardhat.config.js
├── package.json
└── README.md
```

## Démarrage

Installer les dépendances :

```bash
npm install
```

Compiler les contrats :

```bash
npm run compile
```

Exécuter les tests :

```bash
npm test
```
